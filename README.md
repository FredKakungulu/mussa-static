# MUSSA

![MUSSA logo](assets/images/mussa_logo.png)

**Makerere University School of Statistics Association** — the student association for the School of Statistics and Planning at Makerere University.

This is the always-on public site for MUSSA. It stays live between elections so students can learn who the association is, how to become members and supporters, and how voting works when polls open.

## Hosts

| Host                                                               | Serves                           |
| ------------------------------------------------------------------ | -------------------------------- |
| [https://mussaelections.com](https://mussaelections.com)           | This site                        |
| [https://vote.mussaelections.com](https://vote.mussaelections.com) | MUSSA Online Voting System (OVS) |

Voting booth links on this site go to `https://vote.mussaelections.com/auth/voter-login/`.
